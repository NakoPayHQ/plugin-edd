Accept Bitcoin and crypto payments for EDD digital products via NakoPay.

== Description ==

NakoPay for Easy Digital Downloads adds Bitcoin and cryptocurrency payments
to your EDD store. Non-custodial, wallet-to-wallet settlement with a flat
1% fee.

= Features =

* Hosted checkout - customers pay on a NakoPay-hosted page with QR code
* HMAC-SHA256 webhook verification for security
* Automatic payment status updates
* Test mode for development
* Transaction ID storage for accounting

== Installation ==

1. Upload the plugin zip via Plugins > Add New > Upload Plugin
2. Activate the plugin
3. Go to Downloads > Settings > Payments > Gateways and enable NakoPay
4. Enter your API key and webhook secret in the NakoPay settings tab
5. Set the webhook URL in your NakoPay dashboard
